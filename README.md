# Fortaleza Club

Web app de La Fortaleza Barbería (Coacalco, Méx.). El plan completo está en `plan-la-fortaleza.md` y `paso-a-paso.md` del proyecto.

## Correr en tu computadora

```bash
npm install
npm run dev
```

Abre http://localhost:3000.

## Datos de la barbería

Nombre, dirección, horario y WhatsApp están en `lib/negocio.ts`.
